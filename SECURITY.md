# Security policy

**English** · [Español](#español)

## Supported versions

Only the latest release on [GitHub Releases](https://github.com/PabloGonSan8/pdfmusiccraft/releases/latest)
gets fixes. Please update before reporting.

## Reporting a vulnerability

PdfMusicCraft opens PDF files from anywhere, so a PDF that makes it crash, hang, or read or
write files it shouldn't is a security problem.

- **Please don't open a public issue** for it.
- Use GitHub's private reporting: the repository's **Security** tab ▸ **Report a vulnerability**.
  If that button isn't there, open an issue that says only that you have a security report and
  asks for a private contact, without any details.
- Include the app version, your device and Android version, what happens, and if you can, a
  small PDF that shows it. Don't attach documents with personal or confidential content.

This is a small volunteer project: there is no bounty and no guaranteed response time, but
reports are read and answered as soon as possible.

## Problems in PdfCraft's engine

Most of the code here comes from [PdfCraft](https://github.com/storytold/pdfcraft). If the problem
is also in PdfCraft itself, it is worth reporting there too, following their own process.

## Español

### Versiones con soporte

Solo la última versión de [GitHub Releases](https://github.com/PabloGonSan8/pdfmusiccraft/releases/latest)
recibe arreglos. Actualiza antes de informar.

### Informar de una vulnerabilidad

PdfMusicCraft abre PDF de cualquier origen, así que un PDF que la hace cerrarse, colgarse, o leer
o escribir archivos que no debe es un problema de seguridad.

- **No abras una incidencia pública** para ello.
- Usa el aviso privado de GitHub: pestaña **Security** del repositorio ▸ **Report a
  vulnerability**. Si no aparece ese botón, abre una incidencia que solo diga que tienes un aviso
  de seguridad y pida un contacto privado, sin detalles.
- Indica la versión de la app, tu dispositivo y versión de Android, qué ocurre y, si puedes, un
  PDF pequeño que lo muestre. No adjuntes documentos con contenido personal o confidencial.

Es un proyecto pequeño y voluntario: no hay recompensas ni plazo de respuesta garantizado, pero
los avisos se leen y se responden lo antes posible.
